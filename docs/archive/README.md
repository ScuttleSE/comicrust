# Archive

This directory holds history. It is not instruction.

Read a file here only when your current task links to it. Nothing in this
directory describes work in flight. A statement here can be out of date, and
a decision here can be superseded by a later ADR in `docs/decisions.md`.

| Path | Contents |
|---|---|
| `phases/` | The closed phase records, phase 0 through phase 12 |
| `feasibility.md` | The original feasibility study |

The active phase lives in `docs/phases/`. The current state lives in
`docs/current-status.md`.
